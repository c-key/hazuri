# Hazuri Brand Kit

Repository-ready visual assets for Hazuri.

## Contents

- `logos/svg/` — scalable wordmarks, including monochrome and special connection-line variant
- `logos/png/` — rendered PNG versions
- `icons/svg/` — standalone H/connection icons
- `icons/png/` — PNG icons from 16 to 512 px
- `icons/hazuri.ico` — multi-size favicon
- `guidelines/hazuri-brand-board.png` — current visual reference board
- `guidelines/brand.md` — naming, claims, logo and color guidance
- `guidelines/typography.md` — typography guidance; no font files bundled
- `tokens/colors.css` and `tokens/colors.json` — reusable color tokens
- `images/hazuri-banner-reference.png` — banner reference crop from the approved board

## Core copy

**Hazuri — your personal collection of URIs.**

**Hazuri is a small, portable home for your URIs.**
